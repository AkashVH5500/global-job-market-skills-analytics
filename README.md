# Global Job Market & Skills Analytics

## Project Overview

This project analyzes 467 cleaned, real Glassdoor data-science job postings (United States, 2020) to identify
which skills, job roles, seniority levels, and locations are associated with hiring demand and compensation. It
combines Python-based data cleaning, exploratory analysis, statistical testing, visualization, and a small
supervised-learning (AI/ML) component that predicts salary from job features. It was completed for the **IBM
SkillsBuild Data Analytics with AI Academic Internship Program 2026** (BharatCares, in association with AICTE).

> **Scope note:** the dataset is U.S.-only and covers data-science-related postings collected in 2020. All
> findings describe patterns *within this dataset*, not the entire global job market — see Limitations in the
> project report.

## Problem Statement

It is difficult for students, job seekers, and educational institutions to know which specific skills, tools,
seniority levels, and locations are associated with hiring demand and higher pay in the data-science job market.
This project analyzes a real dataset of job postings to identify measurable, statistically-tested patterns rather
than relying on assumption or anecdote.

## Objectives

1. Load and inspect a real job-postings dataset — verify which fields actually exist before analyzing them.
2. Clean the dataset (duplicates, missing values, inconsistent categories) and document every decision.
3. Extract a structured skills taxonomy from free-text job descriptions.
4. Identify the most in-demand skills, overall and by job role.
5. Analyze salary by job role, seniority, and location.
6. Apply basic statistical tests (ANOVA, Pearson correlation, t-tests) without claiming causation.
7. Build a small, transparent AI/ML salary-prediction model and honestly report its accuracy and limitations.
8. Summarize actionable, appropriately-hedged recommendations.

## Dataset

- **Name:** Glassdoor Data-Science Job Postings (2020)
- **Source / URL:** https://github.com/PlayingNumbers/ds_salary_proj (file `eda_data.csv`), originally scraped from Glassdoor.com
- **Description:** 742 raw U.S. job postings (467 after removing duplicates) with job title, full job description text, Glassdoor-estimated salary range, company rating/size/industry/sector, and a seniority tag. 26 skill flags are engineered from the job-description text for this project.
- **License note:** no formal open-data license accompanies this dataset; it has been publicly redistributed on GitHub for years for educational/tutorial use. It is used here strictly for non-commercial, educational purposes with the source credited — see the raw file's origin above before redistributing further.

## Key Findings

*(All figures below are computed directly in the notebook from the actual cleaned dataset of 467 postings — none are assumed.)*

- 275 of 742 raw postings (37%) were exact duplicate scrapes, removed before analysis.
- **Top skills:** Python (55.7% of postings), Statistics (54.2%), Excel (53.5%), SQL (52.0%), Machine Learning (43.5%).
- Skill demand differs sharply by role: Analysts lean on Excel/SQL/Tableau; Data Engineers on SQL/Spark/AWS; Data Scientists on Statistics/Python/ML.
- **Salary rises significantly with seniority** (ANOVA p<0.0001): Senior postings average $122,222 vs. $93,368 for unspecified seniority.
- **Salary varies significantly by U.S. state** (ANOVA p<0.0001); California ($124,449 avg) leads among high-volume states.
- **Machine Learning (+$27,613) and Python (+$21,277) show a statistically significant salary premium** (t-test p<0.0001); Excel and Tableau do not, once their concentration in the lower-paid Analyst role is considered.
- The **AI/ML salary-prediction model** (Random Forest) beats a naive average-salary baseline — MAE $21,815 vs. $31,291, R²=0.437 — showing real but partial predictive signal from role, seniority, location, and skills.
- This dataset has **no remote/hybrid/on-site field**, so work-mode analysis was correctly not performed rather than fabricated.

Full evidence, statistical detail, and limitations for every finding are in the project report.

## Conclusion

Within the scope of 467 cleaned U.S. data-science job postings from 2020, this project found clear, statistically
supported patterns in skill demand, role-specific requirements, and salary by seniority and location, and built a
modest but genuinely predictive AI/ML salary model. The project is explicit throughout about what this single,
U.S.-only, 2020 dataset can and cannot support.
